04 — Engineering

Beautiful and fast.

Progressive loading

HTML and type paint first; the WebGL bundle loads after idle, so 3D never blocks content.

Adaptive quality

GPU tier detection, dynamic pixel ratio and particle budgets keep frame times steady.

Reduced motion

Honors prefers-reduced-motion: native scroll, static scene, no parallax.

Graceful fallback

No WebGL? A CSS gradient composition takes over and every section still works.
